# CodeAlpha Artificial Intelligence Internship Projects

This repository contains the Artificial Intelligence projects completed as part of my **CodeAlpha AI Internship**. The projects cover practical applications of **NLP, machine learning, deep learning, API integration, and generative AI**.

## 🚀 TASKS

### 1. 🌐 Language Translation Tool

A multilingual translation application built with **Streamlit** that allows users to translate text between different languages through an easy-to-use interface.

**Key Features**

* 🌍 Multilingual text translation
* 🔤 Source and target language selection
* 🔊 Text-to-speech support
* 📋 Easy-to-use Streamlit interface
* ⚡ Fast translation workflow

**Technologies**

* Python
* Streamlit
* Translation API
* gTTS
* NLP

---

### 2. 🤖 FAQ Chatbot

An intelligent FAQ chatbot that identifies the most relevant answer to a user's question using **TF-IDF and cosine similarity**, with an **LLM fallback** for questions that cannot be answered confidently from the FAQ knowledge base.

**Key Features**

* 💬 Natural-language question answering
* 🔎 TF-IDF-based FAQ matching
* 📊 Similarity-based response selection
* 🧠 LLM fallback for unmatched queries
* ⚡ FastAPI backend
* 🔌 REST API architecture

**Technologies**

* Python
* FastAPI
* NLP
* Scikit-learn
* TF-IDF
* Cosine Similarity
* LLM API

---

### 3. 🎵 MusicGenAI

A deep-learning-based music generation system that learns patterns from MIDI sequences and generates new musical compositions using an **LSTM neural network**.

**Key Features**

* 🎼 MIDI dataset processing
* 🎹 Note sequence extraction
* 🧠 LSTM-based music generation
* 🎵 Generation of new MIDI sequences
* 🌐 Web-based dashboard
* 💾 MIDI file export

**Technologies**

* Python
* TensorFlow / Keras
* LSTM
* Music21
* MIDI
* Streamlit

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/shreeyy18-git/CodeAlpha-Internship-Projects.git
cd CodeAlpha-Internship-Projects
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it:

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

Install the required dependencies for the project you want to run:

```bash
pip install -r requirements.txt
```

Then follow the instructions in the respective project directory.
